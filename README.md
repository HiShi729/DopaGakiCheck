# ドパガキ診断 — 文字なしの短編物語を使ったクイズゲーム

**絵本・紙芝居のような、ゆっくりした短編動画を見て、物語の展開や結末を思い出すエンタメ向けAndroidアプリです。**

- **動画候補20本**から、プレイごとに**10本を重複なしでランダム抽選**
- 1本 **18秒**。すべて視聴すると **3分（180秒）**
- 文字・字幕・ナレーション・BGMのないオリジナルの縦型MP4
- 各動画は**起（0〜6秒）→ 承・転（6〜12秒）→ 結（12〜18秒）**の3場面構成
- 動画を見終えると、**全10問が物語理解の4択クイズ**。問題候補は20作品×3問＝**60問**
- 各問題の上に、**その動画の冒頭のサムネイル**を表示。結末の画像は表示しません
- スマートフォンとタブレットの縦・横表示に対応

> **注意:** 「ドパガキ度」はアプリ独自のゲームスコアです。ドーパミン量、依存症、注意機能、記憶力、性格などを医学・心理学的に判定するものではありません。動画のスキップやクイズの途中終了から、その人の理由・能力を断定することもできません。

## 遊び方

1. スタート画面でクイズがあることを確認し、開始します。
2. **20本の候補から抽選された10本**の短編動画を見ます。上スワイプ／スキップボタンで次へ進め、タップで一時停止・再開できます。最後まで再生した動画は自動で次へ進みます。
3. 10本の視聴後、各動画から**1問ずつ**、合計10問の4択クイズに答えます。クイズ画面には、その動画の**冒頭場面を切り出した静止画**を表示します。
4. 正答率、スキップ数、動画視聴時間の概算、答え合わせを表示します。途中でクイズを終了することもできます。

### 動画・クイズ制作方針

**動画内では文字を表示しません。** 前置き・人物・状況を静かに示し、後半で出来事が起こり、最後に結末が映像から分かる構成です。1場面約6秒、視点はほぼ固定、音声や過度なテロップ・エフェクトはありません。

色、物の数、動画の再生順、文字情報の丸暗記を問う問題は廃止しました。出題は「最後にどうなったか」「途中で何が起きたか」「主人公はどう対処したか」など、**実際の映像を見ることで判断できる出来事や因果関係**を中心としています。誤答選択肢も同じ物語で起こり得る展開を選び、常識だけで正答できる問題を避けています。

## タブレット対応

Android版では、`smallestScreenWidthDp >= 600` をタブレットとして扱います。タブレットでは縦型動画を中央の9:16領域に表示し、クイズの選択肢を2列に配置します。スタート画面と結果画面は最大幅を制限します。縦横回転でもゲームの進行・動画位置・選択中の回答を維持するようにしています。クイズはスマートフォンでもスクロールでき、長い選択肢や大きな文字設定で切れないようにしています。

ブラウザ版も幅650px以上で動画の中央表示と選択肢の2列表示に対応します。

## スコア

正解数を `C`、クイズ途中終了の場合に `E = 1`（完走なら `E = 0`）とします。

```text
全10問の正答率 [%] = C × 10
ドパガキ度 [%] = min(100, 100 - C × 10 + E × 10)
```

| 状況 | 正答数 | ドパガキ度 |
|---|---:|---:|
| 全問正解 | 10 | 0% |
| 7問正解で完走 | 7 | 30% |
| 7問正解で途中終了 | 7 | 40% |
| 3問正解で途中終了 | 3 | 80% |

これは**エンタメ用の換算**であり、科学的な診断基準や能力評価ではありません。

## Android Studioで起動

必要な環境: Android Studio、JDK 17、Android SDK Platform 36。初回セットアップ時はGradle関連ファイルの取得にネット接続が必要です。

1. リポジトリを取得し、プロジェクトルートをAndroid Studioで開きます。
2. SDK Managerで **Android SDK Platform 36** を導入し、Gradle Syncを行います。
3. Android端末（USBデバッグ）またはエミュレーターを選択し、**Run**します。

ターミナルからビルドする場合:

```sh
./gradlew assembleDebug
```

完成した場合のAPK: `app/build/outputs/apk/debug/app-debug.apk`。

Gradle Wrapper JARが不足する環境では、Android Studioのプロジェクト同期・公式Gradle Wrapperの再生成が必要になる場合があります。`local.properties` は端末固有のSDKパスを記録するファイルなのでGit管理しません。

## ブラウザお試し版

`web-demo/index.html` を開いてください。`stories.js`、`game-engine.js`、`clips/`、`stills/` が必要です。ブラウザの自動再生制限により、再生開始に操作が必要な場合があります。

    GameSessionTest.java         Javaのゲームロジックテスト

### 問題データの編集・動画再生成

```sh
# tools/stories.py を編集した後
python tools/build_stories.py

# 動画を再生成（Pillowとffmpegが必要）
python tools/render_picturebooks.py

# JavaとJavaScriptのルールテスト
sh tests/run_tests.sh
```

動画の3場面のイラストは `tools/render_picturebooks.py` に定義されており、サムネイルは**第1場面だけ**から生成されます。映像の3場面と、`tools/stories.py`の解説・設問内容が一致するように編集してください。生成物は本リポジトリに含まれます。

## 検証

- Java / JavaScriptゲームロジック: **各2,000セッション**で20本から10本の重複なし抽選、全10問の物語問題、正解位置シャッフル、満点、途中終了ペナルティを検証。
- Chromium: **390×844 / 360×640 / 800×1280 / 1280×800** で実際のMP4デコード、各10問のサムネイル表示、正答、途中終了、2列表示、横はみ出し防止を確認。
- MP4: 20本すべてH.264、432×768、18.000秒、音声ストリームなし。生成コードは動画内に文字・字幕を描画しません。
- **未検証:** Android APKのビルドと実機／エミュレーターでの動作。
