# ドパガキ診断 — Androidアプリ（ソース一式）

10本の**オリジナル・縦型MP4**を、YouTube Shorts風の全画面UIで1本ずつ表示する記憶ゲームです。
各動画は18秒（**10本 × 18秒 = 180秒**）。上スワイプ・スキップ、最後まで見たら自動送りに対応します。
動画10本を見終えると、ランダムに出題される4択クイズ10問が始まります。

**重要:** 「ドパガキ度」はゲーム内で定義した独自の数値です。ドーパミン量、依存症、集中力、性格を科学的に診断できる指標ではありません。
クイズを途中終了した理由も、アプリから特定できません。

## スタート画面のクイズ予告

動画の開始前に「このあと、クイズを出します。」という案内を表示します。動画10本の視聴後に、内容や再生順から4択10問が出題されること、スキップした動画も出題対象になることを事前に説明します。Android版とブラウザ版に同じ案内を実装しています。

## v1.2の変更点

- 10本の動画から内容問題を各3候補ずつ合計30問用意し、異なる8動画から1問ずつ抽選。さらに再生順の問題2問を加えて10問出題
- クイズはスクロール不要を目指したコンパクトレイアウト（Android実機では未検証）
- 結果には動画の実視聴時間、全編視聴時の03:00、短縮時間を表示
- VideoViewの表示・動画URI設定順序を見直し、再生素材をソース配布ZIPに同梱
- ランチャーアイコンを追加

## 追加した機能（v1.1）

1. **再生順を毎回シャッフル。** 10本を重複なく表示。スキップしてもその動画は再生位置に数えられます。
2. **8問は映像内容、2問は映像の表示順。** 毎回ランダムに異なる動画を選択します。
3. **順番問題は動画の静止画付き。** 「この動画は何番目に流れましたか？」と出題。正解はその回の実際の並びにより決定します。
4. **クイズの問題順・内容問題の選択肢位置もランダム。** 同じ記号を覚えるだけでは解けません。
5. **クイズ途中終了。** 上部・下部の「途中終了」ボタン、またはクイズ中の戻る操作で確認ダイアログを開き、結果画面に遷移できます。
6. **未回答は不正解、途中終了は追加10ポイント。** 未回答の設問があっても結果表示・答え合わせできます。

## 画面と操作

- **スタート:** 10動画、180秒、10問であることを提示。
- **動画フィード:** 縦動画を再生。上スワイプまたは「スキップ」で次へ。タップで一時停止／再開。動画終了後は自動送り。先の動画へは戻れません。
- **クイズ:** 4択を選んで確定。内容問題と、動画静止画を示す順番問題の2種類。途中終了も可能です。
- **結果:** ドパガキ度、全10問の正答率、回答済み数、動画スキップ数、再生時間の概算、一時停止回数、答え合わせ、結果コピー／シェア、再挑戦。

## スコア

10問での正解数を `C`、クイズを途中終了した場合を `E = 1`（完走した場合は `E = 0`）とします。

```text
全10問の正答率[%] = C / 10 × 100 = C × 10
ドパガキ度[%] = min(100, 100 - C × 10 + E × 10)
```

| 状況 | 正解 | 回答済み | 途中終了 | ドパガキ度 |
|---|---:|---:|:---:|---:|
| 全問正解 | 10問 | 10問 | いいえ | 0% |
| 7問正解 | 7問 | 10問 | いいえ | 30% |
| 7問正解でやめた | 7問 | 7問 | はい | 40% |
| 3問正解でやめた | 3問 | 3問 | はい | 80% |
| まだ答えずやめた | 0問 | 0問 | はい | 100% |

この換算はエンタメ用のルールであり、心理学的な閾値・医学的診断基準ではありません。早期終了は「中断」という観察可能なイベントとして記録し、「集中できなかった」と断定しません。

## Android Studioで起動

事前準備: Android Studio、JDK 17、Android SDK Platform 36、インターネット接続（初回のGradle／Android Gradle Plugin取得に必要）

1. このフォルダを展開します。
2. Android Studioを開く**前に**、macOS / Linux はプロジェクトルートで `./gradlew --version` を実行します。Windows は `gradlew.bat --version` を使用します。公式ラッパーJARを取得してSHA-256を検証します。
3. Android Studioの **File > Open** から `DopaGakiCheck` を選択します。
4. SDK Managerで **Android SDK Platform 36** をインストールし、Gradle Syncを行います。
5. Android端末のUSBデバッグまたはエミュレーターを使い、Android Studioの **Run** を押します。

ターミナルでAPKをビルドする場合:

```sh
./gradlew assembleDebug
```

成功時のインストール用APKの出力先:

```text
app/build/outputs/apk/debug/app-debug.apk
```

指定バージョン: Android Gradle Plugin **8.13.2**、Gradle **8.13**、`compileSdk=36`、`targetSdk=35`、`minSdk=26`。
アプリの通信権限はなく、アカウント・広告・外部APIは使用しません。

**ビルド確認の限界:** この作成環境にはAndroid SDK、Gradleキャッシュがなく、外部バイナリの取得も制限されています。Android版のAPKビルド・端末上での実行テストは実施していません。この成果物はAndroid Studioでビルドする**ソースプロジェクト**であり、既成のAPKではありません。

## 実施した検証

- **Java・JavaScriptゲームロジック:** 各1,200セッションで、10動画重複なし、8+2問、順番の正答、選択肢の重複なし、満点、途中終了ペナルティを検証し、すべて通過。
- **ブラウザ画面:** Chromiumで動画の遷移（スキップ）、順番問題の静止画、10問の採点、3問正解後の途中終了（スコア80%）、未回答7問の表示を検証し、通過。
- **動画ファイル:** 10本すべて、`ffprobe` でH.264 / 432×768 / 18.000秒を確認。
- **未検証:** Android APKのビルド／Android実機・エミュレーターでの挙動。

手元のJDKとNode.jsでロジックの検証を繰り返す場合:

