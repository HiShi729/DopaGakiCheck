# ドパガキ診断 — ブラウザお試し版

`index.html` をChromeなどのブラウザで開くとオフラインで試せます（フォルダ内の `game-engine.js`、`clips/`、`stills/` が必要です）。

- 10本の縦型動画（各18秒）を毎回ランダムな順番で再生
- 上スワイプまたはボタンでスキップ、動画終了後は自動送り
- 内容問題8問 + 動画静止画による再生順の問題2問（選ぶ動画と設問順もランダム）
- クイズ中の「途中終了 ×」「ここでクイズをやめる」で採点に進める
- 全10問の正答率を用い、途中終了の場合だけドパガキ度に10ポイント加算（最大100）
- 結果画面には回答済み数・正答・未回答・スキップ数を表示

本お試し版は **Androidのインストール用APKではありません**。Android版は上位フォルダをAndroid Studioに開いてビルドしてください。

「ドパガキ度」は医学・心理学的な診断指標ではなく、ゲーム内の独自スコアです。
